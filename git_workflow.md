# TASK 4 — Quản trị nghiệp vụ & tiến độ Sprint

## Branch
`chore/sprint-management`

## Quy trình làm việc

1. Checkout branch này trước khi bắt đầu:
   ```bash
   git checkout chore/sprint-management
   ```

2. Sau khi hoàn thành, commit và push:
   ```bash
   git add .
   git commit -m "feat: <mô tả thay đổi>"
   git push origin chore/sprint-management
   ```

3. Tạo Pull Request về `main` khi xong task.

## Lưu ý
- Không làm việc trực tiếp trên `main`.
- Mỗi commit nên rõ ràng, tập trung vào một thay đổi.
